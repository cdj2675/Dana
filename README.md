# Dana

현재 버전: **1.1.0** (화면 왼쪽 위 이름 옆에 표시)

저녁 있는 삶을 위한 디자인 검수 자동화

맨 위 탭이 두 개입니다.

- **디자인** — 과업지시서·원고·디자인 자료를 올리면 질문 몇 개와 확정 버튼 세 번으로 원고 쪽수만큼의 제안서 초안(PPTX)을 만듭니다.
- **검수** — 디자인(PDF·SVG·PNG·JPG)을 기준 원문·디자인 시스템과 맞춰 검수하고, 결과를 적용해 PPTX·SVG·PNG·JPG로 추출합니다.

두 탭은 한 프로젝트를 같이 씁니다. 디자인 탭에서 만든 쪽·디자인 시스템·원고가 그대로 검수 탭의 입력이 됩니다.

## 디자인 탭

전략 문서 「Dana 디자인 모드 전략」(2026-11-03)을 따릅니다.

| 단계 | 사용자가 하는 일 | 산출물 |
|---|---|---|
| 1 자료 올리기 | 과업지시서·원고·디자인 자료를 세 칸에 끌어다 놓기, 추출 카드 확인 | 프로젝트 자산 |
| 2 디자인 시스템 | 무드 3개(공공 네이비·그린·모노) 중 고르기, 색 1~2개 조정, 아이콘 바꾸기 | **확정 1** 디자인 가이드 v1.0 (`.md` + `tokens.json`) |
| 3 자료 분석 | 평가 항목 ↔ 원고 절 연결 중 틀린 것만 고치기 | 배점 매핑표 |
| 4 페이지 플랜 | 보완 제안 수용·보류, 인포그래픽 유형 바꾸기 | **확정 2** 페이지 플랜 |
| 5 샘플 3쪽 | 배점 높은 절의 3쪽을 A/B로 보고 고르기 | **확정 3** 스타일(가이드 v1.1) |
| 6 전체 생성 | 보드에서 쪽을 눌러 프리셋으로 고치기 | 초안 보드 |
| 7 검수·출력 | 검수 결과 반영·확인 후 형식 고르기 | PPTX·PDF·PNG/JPG·SVG·엑셀 |

규칙

- **과업지시서가 최상위**: 글자 크기·쪽수·블라인드 같은 제한 조항은 화면 위 배너에 잠금으로 고정되고, 디자인 시스템의 하한·상한이 됩니다. 애매한 조항은 「확인 필요」로 올라와 사용자가 확정합니다.
- **원고 불변**: 원고 1쪽 = 디자인 1쪽. 원고에 없는 문장·수치는 만들지 않고, 줄바꿈·불릿 나누기만 자동으로 합니다. 보완 제안(부족·과잉·도식화 기회·분량 조정)은 목록으로만 남깁니다.
- **배점은 밀도**: 배점 ÷ 쪽수로 도식 밀도와 샘플 순서를 정합니다. 쪽마다 큰 도식은 1개, 같은 패턴이 3쪽 연속이면 두 번째 후보로 바꿉니다.
- **인포그래픽 패턴 10종**: 불릿, 카드(2·3열+아이콘), 표, 라벨 표, KPI 타일, 흐름, 순환(되돌이표), 허브, 타임라인, VS 대비 + 사진 프레임·리드 박스·결론 배너.
- **글자 맞춤**: 올린 TTF·OTF로 폭을 재서 어절 단위로 줄을 나누고, 남는 높이를 간격·카드·표 행에 나눠 본문 끝선까지 채웁니다. 넘치면 간격 → 아이콘·여백 → 큰 도식 → 줄 간격 순으로 줄입니다.
- **편집 가능한 PPTX**: 글상자·기본 도형(쉐브론·둥근 사각형 등)·표로 만들고, 한글 서체 속성(동양어 문자 집합·panose)을 채워 다른 PC에서도 줄바꿈이 같게 합니다.
- **출력 전 검수**: 내보내기를 누르면 검수 탭이 먼저 돌고, 오류 0 또는 「확인함」 처리 뒤에 내보냅니다. 과업지시서 위반은 확인 처리로 넘길 수 없습니다.

아직 하지 않은 것: 레퍼런스 이미지에서 컴포넌트 스타일 학습(지금은 색만 뽑음), 원고 요약 승인(노란 점), 글자 단위 프리셋(키우기·강조·한 줄로), 벡터 PDF(지금은 250dpi 이미지 PDF).

## 검수 탭

`디자인(필수)` + `디자인 시스템` 또는 `기준 원문` 중 하나 이상

| 올린 자료 | 하는 검사 |
|---|---|
| 디자인 + 디자인 시스템 | 디자인 시스템 규칙(여백·헤더·쪽 번호·글자 크기·글꼴·색·그림자 등), 오탈자 후보, 표기 통일, 아이콘 대장 |
| 디자인 + 기준 원문 | 원문 대조(누락·글자 다름·원문에 없음), 수치·조항, 오탈자 후보, 표기 통일 |
| 셋 다 | 모든 검사 |

1. **자료 올리기** — 디자인 / 디자인 시스템(MD·PDF·PPTX·DOCX·HWPX·JSON·이미지) / 기준 원문(PPTX·DOCX·HWPX·PDF·TXT)
2. **검수** — 쪽별 결과, 항목별 목록, 엑셀 내려받기
3. **결과 적용** — 쪽 범위와 항목을 골라 SVG에 반영(PDF·이미지는 수정 목록)
4. **추출** — PPTX·SVG·PNG·JPG

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀, 스타일, 검수 탭 전체 |
| `design-data.js` | 디자인 탭: 과업지시서·원고·디자인 자료 읽기, 폰트 정보, 배점 분석 |
| `design-layout.js` | 디자인 탭: 무드·토큰·아이콘, 패턴 판별, 쪽 배치, 캔버스·SVG·PPTX·PDF 그리기 |
| `design-ui.js` | 디자인 탭: 탭·제약 배너·7단계 화면·보드·검수 연계·내보내기·저장 |

claude.ai 아티팩트로 게시할 때는 `python3 bundle.py`로 세 `.js`를 넣은 한 파일(`dist/dana.html`)을 만들어 올립니다. Vercel은 저장소 파일을 그대로 씁니다.

## 실행 환경

claude.ai 아티팩트로 게시해 쓰도록 만들었습니다. 아래 기능은 claude.ai 안에서만 동작합니다.

- 작업 공간 저장(내 공간·파티): `window.claude.use('db')`, `use('user')` — 디자인 탭의 확정 상태(가이드·매핑·플랜·스타일)도 여기에 저장
- Claude로 읽기: `use('sample')` — 디자인 시스템 문서·이미지 글자, 과업지시서 조항·배점, 평가 항목 ↔ 원고 절 연결
- 파일 내려받기: `use('downloads')`

일반 웹 서버에서 열면 업로드·검수·디자인 생성은 되지만 저장과 Claude 읽기는 꺼집니다(과업지시서·연결은 문서에서 직접 찾는 방식으로 대신함). 내려받기는 브라우저 기본 방식으로 동작합니다.

## 자료 보관

- 올린 과업지시서·원고·디자인·폰트 파일은 저장하지 않습니다(브라우저 화면에만). 원고를 다시 올리면 저장된 확정 상태를 이어 붙입니다.
- 디자인 시스템·허용 목록·용어집·기준 수치·적용 결과·디자인 탭 확정 상태는 작업 공간에 저장합니다.
  - 내 공간: 본인만 읽음
  - 파티: 16자리 파티 코드로 AES-GCM 암호화, 코드를 아는 사람만 읽음

## 사용 라이브러리 (CDN)

JSZip 3.10.1, pdf.js 3.11.174, SheetJS 0.18.5, PptxGenJS 4.0.1, jsPDF 2.5.1(PDF 내보낼 때만), Google Fonts Noto Sans KR(폰트를 올리지 않았을 때의 내장 서체)

## 버전과 업데이트

- 버전 번호는 `index.html`의 `const VERSION` 한 곳에서 관리합니다. 고칠 때마다 이 값과 아래 변경 기록을 함께 올립니다.
- 작은 수정은 끝자리(1.0.**1**), 기능 추가는 가운데 자리(1.**1**.0)를 올립니다.
- 팀원은 공유받은 claude.ai 링크를 새로고침하면 최신 버전을 씁니다. 저장해 둔 작업 공간은 업데이트해도 유지됩니다.
