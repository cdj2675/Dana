# Dana 1.0

저녁 있는 삶을 위한 디자인 검수 자동화

디자인(PDF·SVG·PNG·JPG)을 기준 자료와 맞춰 검수하고, 결과를 적용해 PPTX·SVG·PNG·JPG로 추출하는 웹 도구입니다. 파일 하나(`index.html`)로 동작합니다.

## 검수 구성

`디자인(필수)` + `디자인 시스템` 또는 `기준 원문` 중 하나 이상

| 올린 자료 | 하는 검사 |
|---|---|
| 디자인 + 디자인 시스템 | 디자인 시스템 규칙(여백·헤더·쪽 번호·글자 크기·글꼴·색·그림자 등), 오탈자 후보, 표기 통일, 아이콘 대장 |
| 디자인 + 기준 원문 | 원문 대조(누락·글자 다름·원문에 없음), 수치·조항, 오탈자 후보, 표기 통일 |
| 셋 다 | 모든 검사 |

## 흐름

1. **자료 올리기** — 디자인 / 디자인 시스템(MD·PDF·PPTX·DOCX·HWPX·JSON·이미지) / 기준 원문(PPTX·DOCX·HWPX·PDF·TXT)
2. **검수** — 쪽별 결과, 항목별 목록, 엑셀 내려받기
3. **결과 적용** — 쪽 범위와 항목을 골라 SVG에 반영(PDF·이미지는 수정 목록)
4. **추출** — PPTX·SVG·PNG·JPG

## 실행 환경

claude.ai 아티팩트로 게시해 쓰도록 만들었습니다. 아래 기능은 claude.ai 안에서만 동작합니다.

- 작업 공간 저장(내 공간·파티): `window.claude.use('db')`, `use('user')`
- 디자인 시스템 문서·이미지 글자 읽기: `use('sample')`
- 파일 내려받기(엑셀·추출): `use('downloads')`

일반 웹 서버에서 열면 업로드·검수·적용은 되지만 저장, Claude 읽기, 내려받기는 꺼집니다.

## 자료 보관

- 올린 원문·디자인 파일은 저장하지 않습니다(브라우저 화면에만).
- 디자인 시스템·허용 목록·용어집·기준 수치·적용 결과는 작업 공간에 저장합니다.
  - 내 공간: 본인만 읽음
  - 파티: 16자리 파티 코드로 AES-GCM 암호화, 코드를 아는 사람만 읽음

## 사용 라이브러리 (CDN)

JSZip 3.10.1, pdf.js 3.11.174, SheetJS 0.18.5, PptxGenJS 4.0.1
